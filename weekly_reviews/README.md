# Weekly Research Review Workflow

## Purpose

A weekly review converts daily activity into research decisions. It should report evidence, uncertainty, and changes in direction rather than reward activity volume.

Create `weekly_reviews/YYYY-Www.md` only after an active research week has been reviewed. Use the ISO week number, and do not create reviews for weeks with no research activity.

## Review Workflow

1. Read that week's daily logs.
2. Verify links to notes, papers, code, experiments, and results.
3. Compare completed work with the current roadmap stage and exit criterion.
4. Triage new backlog items, priorities, duplicates, and resolved questions.
5. Record decisions and reasons, including abandoned or inconclusive directions.
6. Select one to three evidence-producing outcomes for the next active week.
