# Literature Matrix

Use this file as an index and comparison view; follow the reading workflow in `papers/README.md`. Add one row only after checking the paper itself. Use `TBD` when a field cannot yet be supported, and do not copy an abstract's claim into `Main Result` as if it had been independently verified.

Allowed review states are `queued`, `skimmed`, `read`, `verified`, and `reproduced`. Use `verified` only after checking the cited evidence and `reproduced` only when a linked reproduction record exists.
